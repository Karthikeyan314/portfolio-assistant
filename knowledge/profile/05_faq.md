## How does this assistant work?

It splits Karthikeyan's profile and project documentation into short passages, finds the passages most relevant to your question with BM25 keyword search, and asks an open model on Hugging Face to answer from those passages only, citing them. The code is at https://github.com/Karthikeyan314/portfolio-assistant.
